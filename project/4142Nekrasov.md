# 1. ВВЕДЕНИЕ

В современном мире управление личным временем и задачами стало одной из ключевых задач каждого человека, особенно в условиях высокой загруженности информацией и необходимостью постоянно планировать свои действия. Мобильные приложения, предназначенные для ведения журналов и списков задач (todo), играют важную роль в организации ежедневной рутины. Они помогают пользователям управлять своими целями, отслеживать выполненные задачи и создавать эффективные планы на будущее.

Проектирование мобильного приложения, совмещающего возможности ведения личных записей (журналов) и управления задачами, актуально, так как оно отвечает потребностям современного пользователя в удобных, многофункциональных и доступных инструментах для организации личных данных и времени. Интеграция таких функций в одно приложение облегчает контроль и планирование, повышает продуктивность, и улучшает управление повседневной жизнью.

Цель проекта: 


**Цель проекта**: разработка мобильного приложения для управления личными журналами и списками задач, с использованием локальной базы данных для хранения данных.
**Задачи проекта**:

1. Провести исследование предметной области и определить требования к функционалу приложения.
2. Спроектировать интерфейс и архитектуру приложения с двумя основными вкладками: "Журналы" и "Списки задач".
3. Реализовать локальное хранение данных с использованием Room для обеспечения доступа к информации без подключения к сети.
4. Разработать и протестировать функционал приложения на Kotlin в среде Android Studio.

## 1.1 Исследование предметной области

Исследование существующих решений на рынке показывает, что современные мобильные приложения для ведения журналов и управления задачами (такие как Notion, Todoist и Google Keep) предлагают пользователю разнообразные возможности для организации личной информации. В приложениях такого рода, как правило, реализован функционал добавления, редактирования и удаления записей, создание напоминаний и задач с возможностью установки приоритетов и сроков.

Цель исследования – понять, какие функции наиболее востребованы у пользователей, и на основе этого разработать приложение, которое будет учитывать основные потребности, включая возможность работы в автономном режиме, использование интуитивно понятного интерфейса и хранение данных на устройстве пользователя.

## 1.2 Проектирование мобильного приложения

Проектирование включает создание двух основных разделов: "Журналы" и "Списки задач". Вкладка "Журналы" будет служить для хранения заметок и личных записей. Вкладка "Списки задач" позволит пользователю создавать и управлять todo-листами, отслеживать прогресс выполнения задач.

В качестве хранения данных будет использоваться локальная база данных Room, которая позволяет эффективно управлять записями и задачами, сохраняя их на устройстве пользователя, даже в отсутствие интернета. Для обеспечения удобства пользователя будет использован материал-дизайн с простым и интуитивным интерфейсом.

## 1.3 Выбор программного обеспечения

Для реализации проекта используется следующая среда разработки:

- Язык программирования: Kotlin
- IDE: Android Studio
- База данных: Room (локальная база данных на основе SQLite)

Этот стек технологий выбран в связи с его популярностью и соответствием современным стандартам разработки мобильных приложений на платформе Android.

## 1.4 Программная реализация

На этапе программной реализации будут применены принципы MVVM (Model-View-ViewModel) для разделения бизнес-логики и пользовательского интерфейса. Room будет обеспечивать безопасное и быстрое хранение данных, а Kotlin позволит использовать функциональные и объектно-ориентированные возможности для удобной работы с данными и компонентами приложения.
